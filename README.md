Pengelolaan Data Buku

Program Python sederhana untuk mengelola data buku menggunakan struktur data Dictionary dan perulangan while.

Penjelasan Kode

1. Data Awal Buku
Membuat dictionary bernama buku untuk menyimpan informasi dasar seperti judul, penulis, dan tahun terbit.

2. Menu Utama (Perulangan)
Menggunakan while True supaya menu terus muncul dan pengguna bisa memilih aksi berulang kali sampai memilih menu keluar.

3. Tampilkan Data
Menggunakan perulangan for dan fungsi .items() untuk melihat semua pasangan key dan isi data buku yang ada saat ini.

4. Tambah Penerbit
Menambahkan key baru bernama "penerbit" ke dalam dictionary berdasarkan input dari pengguna.

5. Ubah Penulis
Mengganti nama penulis lama dengan nama penulis baru yang dimasukkan oleh pengguna.

6. Hapus Penerbit
Mengecek apakah data penerbit ada. Jika ada, data tersebut dihapus menggunakan perintah del.

7. Keluar Program
Menampilkan data buku hasil perubahan terakhir, lalu menghentikan perulangan program dengan perintah break.
